# Curated Public Source Records

Public-source records are intentionally curator-reviewed rather than crawled. Automated access to `https://www.ngcp.ph/media` returned `403` from this development environment on 2026-08-07, so no public NGCP claim has been copied or inferred into the runnable corpus.

Before adding a public record to `../manifest.json`, verify that its source is publicly accessible and add a concise factual summary with:

- the canonical HTTPS source URL;
- source title and publication date;
- retrieval date;
- attribution; and
- a reviewed mapping to one of the existing domains and simulated roles.

Do not mirror full articles, ingest non-public material, or add public records that lack source metadata. Once approved and entered into the manifest, the ingestion script will upload and index the record with the same citation guarantees as the synthetic corpus.
